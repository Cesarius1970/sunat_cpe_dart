## 0.1.0

- Initial release of `sunat_cpe_nubefact`.
- Implement `NubefactProvider` (`OseProvider`) for Nubefact JSON REST API v1.
- Add `NubefactCatalogMapper` for translating SUNAT catalogs to Nubefact integer codes.
- Support invoices, boletas, credit/debit notes, voided communications, despatch advices (remitente/transportista), retentions, perceptions, and status queries.
